OminiFlow for Odoo 19

Connect Odoo with your existing OminiFlow PHP platform

OminiFlow is a WhatsApp commerce and messaging platform. This module is an Odoo 19 connector only. It talks to the existing PHP backend over HTTPS. It does not replace OminiFlow and does not access the OminiFlow database directly.

Features

  • Secure connection with a Developer Portal API key
  • Test Connection against the real /api/wpbox/me endpoint
  • Product catalog synchronization (SKU + OminiFlow id)
  • Customer synchronization from WhatsApp contacts (phone + id)
  • Sync logs with success and failure filters
  • Hourly scheduled sync
  • HMAC-verified inbound webhooks

Supported integrations

This connector uses the public OminiFlow REST APIs used by the Developer Portal and catalog tools:

  • GET /api/wpbox/me
  • GET/POST/PUT /api/wpbox/ecommerce/products
  • GET /api/wpbox/getContacts
  • POST /api/wpbox/makeContact
  • Developer Portal webhooks (X-Ominiflow-Signature)

Sales order sync and warehouse inventory moves are not included, because OminiFlow does not currently publish those REST APIs.

Setup

  1. Install the module in Odoo 19.
  2. Create an OMINI_ API key in the OminiFlow Developer Portal.
  3. Open OminiFlow → Connections and enter the base URL and API key.
  4. Click Test Connection.
  5. Enable product and/or customer sync, then run Sync or wait for the hourly cron.

Synchronization

Products are matched by OminiFlow id, then by SKU. Contacts are matched by OminiFlow id, then by phone, then by email. The same sync can be run twice without creating duplicate Odoo records.

Catalog stock_quantity is stored as a product field for reference. Odoo warehouse quantities are not changed.

Requirements

  • Odoo 19.0
  • OminiFlow PHP application with Developer Portal API keys
  • Network access from the Odoo server to the OminiFlow URL
